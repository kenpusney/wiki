# Obsidian Rules

These conventions apply because this repo is also an Obsidian Vault.

## File Moves

- When moving an `.md` file, also move any related content in the same directory's `assets/` folder alongside it.
- Preserve filename compatibility with Obsidian: avoid characters that break linking or search.

## Links

- Use Obsidian-style wikilinks `[[file]]` or `[[text|file]]` for internal references.
- External links use standard Markdown.

## Assets

- Images and attachments belong in an `assets/` folder next to the note that references them, or under `content/static/` for shared assets.
