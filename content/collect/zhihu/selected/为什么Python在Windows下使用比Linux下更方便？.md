# 为什么Python在Windows下使用比Linux下更方便？

[知乎链接](https://www.zhihu.com/question/24075869/answer/34396847)

---------

因为Python有一条定律：

> "Whenever you find a python executable pre-installed, it's the wrong version."（[ref](http://programmers.stackexchange.com/questions/115851/is-perl-still-a-useful-viable-language#comment261539_115859)）

而Windows是不会预装Python的。

就是这样。
