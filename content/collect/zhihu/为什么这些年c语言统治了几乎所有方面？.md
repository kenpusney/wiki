# 为什么这些年c语言统治了几乎所有方面？

[知乎链接](https://www.zhihu.com/question/26987428/answer/34809725)

---------

> 一切编程语言都是面向特定领域（Domain-Specific）的。（[Kimmy's First Law of Programming Language](http://blog.kimleo.net/post/46977_3ced116)）

C语言也不例外。
就只能拿来**写底层**或者**实现其他编程语言**。
所以根本不存在“**统治**”之说。

并且Java / C#（我觉得这就是题主所说的.net）/ Python / Golang，本来就不是为了替代C语言，也没那个能耐替代C语言。
毕竟如果你只是做应用，还是要优先考虑**开发效率**而非**（C语言一般的）运行效率**。
