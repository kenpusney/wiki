# Linux 与 Windows 相比，优点体现在哪？

[知乎链接](https://www.zhihu.com/question/21219829/answer/59433018)

---------

然而Office并不只是我保持用Windows的原因。
主要是这里并没有什么宗教精神，和伦理问题。

－ 说Linux开源的你们显然并没有听说过WinRK。
－ 说Linux安全的你们真的需要好好补补课，看看到底这些年信息安全和操作系统a发展成了什么样子。一个内核还要靠周边工具控制保持自身的安全，也就只有Linux了吧。（如果你们非要自己拿着Administrator权限玩，活该被黑！
－ 说Linux自动化工具完善的，可能在你们还不知道Shell Script是什么的时候，Windows 就已经有个[Windows Script Host](https://en.wikipedia.org/wiki/Windows_Script_Host)在默默地让你们开心地玩了。在你们还在纠结Bash中的字符串到底怎么玩的时候PowerShell就已经类型化了。好好看看最丑的VBScript和JScript吧，比你们用的七十年代的Shell Script完美多了。

唯一一个能够让我有想法切换回Unix-like的系统的原因，就像是 [@pansz](https://www.zhihu.com/people/7240b2ae38836f4837c2d7355b2ee72d)潘总说的，有些东西在这上面的体验比Windows下更好。

更多的原因其实是我被迫不得不用那个软件。
