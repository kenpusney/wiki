# 为什么说C++是一个十年也填不上的坑？

[知乎链接](https://www.zhihu.com/question/38279818/answer/77133300)

---------

C语言有很多个变种：
K&R C / ANSI C / ISO C / ISO C99 / ISO C11 / Turbo C / GNU C / Visual C / 谭 C / 薛 C。（看我国教育贡献多明显。
如同某匿名用户说的，C++是一个语言联邦，同时也是一个拥有丰富变种的语言。
先说变种：
- C with classes

- C++ARM

- ISO C++

- ISO C++/TR1

- C++/Qt

- C++/Boost

- C++/GacUI

- C++11

- C++14

- C++1z

- std::experimental C++

- GNU C++

- Visual C++ / C++/CLI / C++/CX

- Objective-C++

- ...

再说子语言：
1. 绝大多数C语言变种

1. cpp(C preprocessor)

1. Object-oriented C++ (class / inheritance / exceptions)

1. template C++

1. meta-programming C++

1. functional C++

1. STL C++

1. Concepts

1. Reflections

1. ...

不知道题主您到底说的是哪一个坑十年填不完？
