# 让你觉得惊叹无比的代码片段或者正则表达式？

[知乎链接](https://www.zhihu.com/question/23201595/answer/23951725)

---------

```text
static pure bool longMonth (uint m){
  return !(m & 1) == (m > 7);
}
```
